# Body-Compostion-Data-Analysis
Exploratory data analysis project using AI to identify body compostion trends, correlations, and statistical outliers.
![Screenshot_14-4-2026_16317_partyrock aws](https://github.com/user-attachments/assets/4dccc86b-0a5e-4395-b074-47beb9b3c103)
## What This App Does
- Built in PartyRock (Amazon Bedrock) as part of the AWS AI Practitioner Challenge with Udacity.
- Helps users explore body composition trends using AI-driven analysis.
- Uses multiple input fields and output widgets so the same analysis can be reused, not just done once in a chatbot.

## What I Learned
- How to turn a one-time chatbot idea into a reusable app with input and output widgets.
- How to design a simple AI workflow in PartyRock (Amazon Bedrock).
- How to think about user inputs, outputs, and shareable tools instead of single conversations.
